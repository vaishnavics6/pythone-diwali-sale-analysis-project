# Python_Diwali_Sales_Analysis
Python project for beginners- Analyze Diwali sales data to improve customer experience and sales
🪔 Diwali Sale Analysis using Python
📌 Project Overview

This project focuses on analyzing Diwali Sale Data using Python. The goal is to explore customer behavior, purchasing trends, and product sales during the festive season. By performing data cleaning, exploration, and visualization, the analysis provides insights that can help businesses improve marketing strategies and boost sales in future campaigns.

🛠️ Technologies & Libraries Used

Python

Pandas → For data cleaning and manipulation

NumPy → For numerical computations

Matplotlib & Seaborn → For data visualization

Jupyter Notebook / VS Code → For running and documenting the analysis

📂 Dataset

The dataset contains customer purchase details during a Diwali sale. Typical columns include:

User_ID → Unique customer ID

Cust_name → Customer name

Product_ID → Unique product ID

Gender → Gender of the customer

Age Group → Age bracket of customers

State → Customer location

Marital_Status → Marital status of customers

Occupation → Profession of customers

Product_Category → Category of the purchased product

Orders → Number of orders placed

Amount → Total purchase amount

🔍 Steps Performed

Data Collection

Imported the dataset into Python using Pandas.

Data Cleaning

Checked for null values and duplicates.

Removed/handled missing data.

Converted datatypes where required.

Exploratory Data Analysis (EDA)

Analyzed gender-wise, age-wise, and state-wise sales.

Checked customer occupation trends.

Compared product categories and order amounts.

Data Visualization

Created bar charts, pie charts, and histograms.

Visualized top-selling product categories and states.

Compared spending behavior of different customer groups.
